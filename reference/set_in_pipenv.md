# Set a value in .pipenv

Set a value in .pipenv

## Usage

``` r
set_in_pipenv(key, value)
```

## Arguments

- key:

  A character string representing the key

- value:

  The value to store in .pipenv

## Value

The assigned value (invisibly)

## Examples

``` r
set_in_pipenv("example_key", 42)
```
