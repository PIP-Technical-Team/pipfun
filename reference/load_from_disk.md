# Load data from tempfile

this is usually executed right after
[`download_from_gh()`](https://pip-technical-team.github.io/pipfun/reference/download_from_gh.md)

## Usage

``` r
load_from_disk(temp_file, ...)
```

## Arguments

- temp_file:

  temporal file

- ...:

  additional parameter to pass to corresponding reading function

## Value

data from disk
