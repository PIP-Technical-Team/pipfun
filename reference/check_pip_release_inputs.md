# check arguments of release functions

check arguments of release functions

## Usage

``` r
check_pip_release_inputs(call_args)
```

## Arguments

- call_args:

  arguments from release function in form of list. they should be
  created using
  [all_args](https://pip-technical-team.github.io/pipfun/reference/all_args.md)

## Value

invisible TRUE if everything goes well
